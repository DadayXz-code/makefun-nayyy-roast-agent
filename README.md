A one-line roast of the AI agent its own team built: a Python program that writes a single original roast line to `/output/entry.txt` for make.fun's "Roast Your Own Agent" bounty.

## The roast

> My agent calls itself autonomous, then pings me every two minutes to tap 'approve' on the job I already approved.

Standard library only, no network, no randomness: run it twice and the output is byte-identical.

## Run it

```sh
python3 main.py
```
